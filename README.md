# CodeWars

My Codewars practice solutions, organized by difficulty.

```text
CodeWars/
├── 8-kyu/
│   └── challenge-name/
│       └── solution.js
├── 7-kyu/
│   └── challenge-name/
│       └── solution.js
└── 6-kyu/
    └── challenge-name/
        └── solution.js
```

For each completed kata, create a folder named after the challenge inside its kyu folder, then add your solution. Add other kyu folders as needed.

Existing solution filenames and contents are preserved. The `CoffeeScript` folder contains another JavaScript Swap Values solution and is retained under `8-kyu` so no work is lost. The `.gitkeep` file keeps the currently empty `6-kyu` folder visible on GitHub; remove it when adding your first challenge there.
